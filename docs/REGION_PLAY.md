# 地域別プレイ（Issue #11）

## 初期対応と国数

4題型・6回答バリエーションで、全世界または地域別プレイを選択できます。全世界は197か国・地域が対象です。地域ごとの件数は国マスタの `regionIds` から**自動計算**して表示します。

| 地域 | 件数 |
| --- | ---: |
| 全世界 | 197 |
| アフリカ | 54 |
| アジア | 49 |
| ヨーロッパ | 48 |
| 北アメリカ（中央アメリカ・カリブ海を含む） | 23 |
| 南アメリカ | 12 |
| オセアニア | 14 |

ロシア（RU）、トルコ（TR）、カザフスタン（KZ）はアジア／ヨーロッパ両方に所属し、どちらの地域でも問題として登場します。世界全体では各国1回ずつで197件、地域件数の**合計は200件**です。複数地域に所属していても、同一地域の出題プールで二重にカウントすることはありません。

ジョージア／アゼルバイジャンなどのコーカサスの大陸境界は定義によって異なるため、現行データのアジアのみを維持します。キプロスは現行データのヨーロッパのみを維持します。これはクイズ上の分類であり、政治上の帰属や地位を決めるものではありません。

## 回答方式による出題の違い

- 地図→国名・国旗→国名（入力）：設定地域内の国から出題し、入力名は日本語／英語の現行判定に接続
- 地図→国名・国旗→国名（国名四択）：正解と誤答3候補を**選択地域内**の国から抽選
- 国名→地図：正解国は選択地域内から出題。開始時は地域の**広域視点**を表示します。正解国の位置へ自動移動・強調するのは回答後です
- 国名→国旗：正解国は選択地域内。誤答3候補は設定に従って「出題地域内」または「全世界」から抽選可能

## 少数地域を追加した場合の動作

現在の6地域はいずれも10か国以上です。将来、中央アメリカ／カリブ海などの下位区分を追加してもエラーやループに陥らないよう、次のルールを共通エンジンに導入しました。

- 10問制（無制限・時間制限あり）は**min(10, 地域内の国数)**をそのラウンドの出題数に採用。10か国未満の地域なら、例えば8か国で8問になります
- タイムアタックは候補を使い切るまで重複しないよう抽選し、使い切ったら既存仕様に従って再シャッフルします
- 国名の四択は地域内に4か国以上必要です。4未満なら開始を無効化し、理由を表示します
- 国名→国旗の四択で誤答候補を「地域内」から選ぶ場合も4か国以上必要です。「全世界」を選ぶ場合は、地域内に正解1か国以上あれば候補3件を全世界から抽選できます
- 入力式と地図選択は1か国以上あればゲーム可能です。0件の地域は開始できません
- 各クイズの地域選択欄に「対象国数」と実際の「出題数」を表示し、10問制が短縮されても進行表示と終了判定は正しい上限を表示します

## 実装方針

`src/country-data/regions.ts` が地域ID／日英名称を定義し、国マスタの `regionIds` は配列形式なので、今後新しい下位地域IDを追加してもゲームエンジンの出題抽選ロジックの変更は不要です。表示したい下位区分を追加する場合は、地域定義・該当国の所属・必要に応じて2D地図の初期ビュープリセットを整備します。

`src/features/quiz/RegionSelector.tsx` を3種類の画面コンポーネント（国名回答2題型は共通画面）から呼び出し、表示ラベル・国数・開始可否を一元化しています。ゲームエンジンでは `getEligibleCountries()` が地域判定、`getQuestionLimit()` と `GameSession.questionLimit` が小地域の安全な問題数管理を担当します。

## テスト

`tests/regions.test.mjs` で全世界・6地域 × 6回答形式、越境国の両地域出題、同一国の重複防止、小地域（1〜9件）での進行・完了・時間切れ、四択候補不足時の扱い、共有UI・地図の初期地域視点を確認します。既存の国マスタ、四択候補、各題型のテストも実行します。
