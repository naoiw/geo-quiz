# 国名 → 地図クイズ（Issue #8）

## 遊び方

出題された国名の場所を地図で探して回答します。回答前に正解国を自動で強調・フォーカスしません。

1. 国名を見て地図をドラッグ、ズーム、または表示地域を切り替えて場所を探します
2. 地図をタップ／クリックして国を青色で仮選択します。必要なら何度でも選び直せます
3. 「回答を確定」で採点します。パスも可能です
4. 正解国を黄色で表示してフォーカスし、正誤を確認して「次へ」を押します
5. 10問終了または時間切れでスコア、正答率、回答履歴を表示します

スマホでの誤タップを防ぐため、タップ一回では採点しない選択→確定の二段階方式を採用しました。

## 設定とエンジン

- 出題地域：全世界197か国・地域、または6地域
- 進行方式：10問・時間無制限、10問・時間制限、タイムアタック
- 時間制限：1／2／3／5分（暫定）
- 配点：正答100点、誤答・パス0点（暫定）
- 日本語・英語に対応

NameToMapQuiz.tsx が画面・地図操作を担当し、game-engine/engine.ts が出題、重複防止、国ID照合、採点、パス、時間制限と結果集計を担当します。回答は { format: "map", countryId: selectedCountryId } として共通エンジンに渡します。後続の3D地球儀でもこの契約を使います（#19）。

## 小国と地図の操作

出題対象197件すべてが地図ポリゴンに存在します。小国には透明なタップ領域があり、画面上の幅を確保するため、非拡大の透明ストローク18pxを付けます。黒い円マーカーや黒い角丸枠は追加しません。

地図の「表示エリア」から全世界または6地域の広域プリセットにジャンプできます。地域を選んで開始したときはその地域を初期表示します。正解国へ移動する機能は解答後にだけ使用します。
