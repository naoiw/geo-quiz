# 国名 → 国旗クイズ（Issue #9）

## 遊び方

表示された国名に対応する旗を、4つの候補から選択します。タップ／クリックで回答確定し、正誤・正解を確認して「次へ」進みます。パス、結果画面、回答履歴にも対応します。

- **出題地域：** 全世界197件、または6地域。越境国は複数地域で出題されても同一の国IDを使います
- **誤答国旗の範囲：** 「出題地域内」／「全世界」を独立に切替可能。世界全体が出題地域の場合は両者は同義
- **ゲームルール：** 10問・時間無制限、10問・時間制限、タイムアタック（1／2／3／5分。暫定）
- **採点：** 暫定で正答100点、誤答0点、パス0点
- **日英対応：** 出題国名、選択肢ラベル、結果・操作文言に適用
- **スマホ：** 幅の狭い画面でも2列×2行の国旗候補を表示。SVGの4:3表示比を維持し、画像の切り抜き・引き伸ばしを行わない

## 出題候補の生成

`src/features/quiz/flag-choices.ts` の `createFlagChoices()` に、正答国ID、出題の国候補、全世界マスタ、`FlagChoiceOptions` を渡します。

- 正答の国IDは常に出題候補内の1件で、残り3件は `scope` に従い同地域または全世界から選択します
- 候補の国IDと `flagId` を重複させず、最終選択肢をシャッフルします。テストでは**197件の実SVGファイル内容のSHA-256**に重複がないことも検査します
- **候補となる固有の国旗が4件未満の場合、明示的に例外を送出**します。黙って3択以下にする・他地域へ勝手に拡張する動作はありません。現在の地域6分類はどれも4件以上あるため通常の操作には影響しません
- `rankDistractors` に関数を注入すると、デフォルトのランダム抽出から将来の「似た国旗優先」などへ変更できます。選択候補は地域設定で許可されたものだけです
- 似た国旗は別国として扱い、`answer.format = "flag"` と国IDで厳密判定します。画面上の国旗の代替テキストには国名を含めず、A〜Dの識別子を使用します

## 共通の回答UIとエンジン

`CountryChoiceGrid.tsx` は国名四択・国旗四択で同じクリック・タッチ・正誤の装飾・無効化を使用します。国名四択のデータは従来の `name-choices.ts`、国旗四択は `flag-choices.ts` が生成します。

`NameToFlagQuiz.tsx` が設定、画像表示、時間経過の通知と結果画面を担当し、出題・回答判定・スコアはIssue #5の純粋な `game-engine/engine.ts` を利用します。地図→国名、国旗→国名、国名→地図の既存実装も変更せず同じ基盤に接続します。

## 検証

`tests/name-to-flag-quiz.test.mjs` で全197件と全地域、同じ国旗ID／同一SVGデータの排除、固有候補不足、再現可能な乱数、差し替え可能な誤答抽出、日英の10問進行・誤答・パス・時間切れをテストします。実機でのタッチUX、アクセシビリティ・E2Eの更なる検証は#13/#17で進めます。
