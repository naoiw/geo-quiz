# 品質検証チェックリスト（Issue #17）

本ページは自動テストの範囲と、**人間による実機確認がまだ必要な項目**を区別して記録するためのチェックリストです。未チェック項目は合格を意味しません。

## CIで自動検証する事項

- 国マスタ197件（国ID、国名・読み、地域、分類）の整合性
- 197件の国IDと2Dポリゴン・国旗SVGファイルの一対一対応
- 世界＋6地域、4題型・6回答形式、ja/en、3進行ルールを掛け合わせた252構成の完走・採点・重複防止
- 国名四択と国旗四択の正答1件保証、重複なし、地域内／全世界の誤答プール
- スキップ、誤答、時間切れ、セッション結果
- 小国・島国のピン、日付変更線をまたぐ表示、回答前の正解位置非表示（既存テストと合わせて検証）

実行コマンド：`npm run lint` / `npm run typecheck` / `npm test` / `npm run build`。

## データの特例と出典

- 国マスタに含む非国連加盟の追加対象：台湾（TW）、コソボ（XK）
- 国連オブザーバー：パレスチナ（PS）、バチカン（VA）
- Natural Earthコード対応の例外：PSX→PS、KOS→XK、SDS→SS
- ロシア（RU）、トルコ（TR）、カザフスタン（KZ）は複数地域に属する
- 小国の位置ピンは首都座標でなく地図データの代表点を利用する
- 詳細なデータライセンス・更新版は [DATA.md](DATA.md)、[MAP.md](MAP.md)、[FLAGS.md](FLAGS.md) を参照

検証結果は対象IssueまたはPRに記録し、未検証を「成功」として扱わないでください。
