# 地図 → 国名クイズ（Issue #6）

## 対応範囲

トップページ「地図 → 国名クイズ」から開始できます。共通の `WorldMap` と `src/game-engine/engine.ts` を使用します。出題ごとに国を黄色で強調し、地図をその国付近に移動。国名を入力する方式と四択方式を切り替えてプレイできます。

- **回答方式：** 日本語／英語のテキスト入力、または国名四択。回答中は正解の名前を表示しません。
- **地域：** 全世界197件、アジア48件、ヨーロッパ46件、アフリカ54件、北米23件、南米12件、オセアニア14件。
- **進行：** 10問無制限、10問時間制限あり、タイムアタック。後者2つは1・2・3・5分から選択。
- **結果：** 正答／誤答／パス、正解の国名、次問への遷移、得点・正答率・経過時間・問題ごとの履歴。
- **暫定仕様：** 正答100点、誤答／パス0点、制限時間の候補は今後調整。採点ロジック自体は共通ゲームエンジンが担当します。

## 地図と小国

クイズ画面では `WorldMap` に `readOnly` を渡し、国をタップしても答えを表示せず、国名のアクセシビリティラベルも出力しません。パン・ズームは可能です。出題国のフォーカスは `focusCountryId` で制御します。広域に分布する国は従来の中心座標へ移動し、バチカンなどごく小さい国は12度の表示幅まで自動ズーム。さらに8度まで手動拡大できます。

小国の場所は既存の国境SVGパスを黄色の3pxの線で強調することで示します。以前削除した小国マーカー（上から重ねる丸い表示）や黒い角丸フォーカス枠は復活させません。極端に小さい国の境界は元の1:50mデータ精度に制約があります。

## 回答方法の実装

テキストの確定時に `submitAnswer()` を使います。IME変換中のEnterは送信せず、空文字は送信不可。正答候補は現在選択中の言語の表示名と国マスタの登録済み別名のみです（NFKCなど基本正規化は#5で実装済み）。読み・別表記の登録とIME変換Enter対策はIssue #10で対応済み（[TEXT_ANSWER.md](TEXT_ANSWER.md)）。

四択候補は `src/features/quiz/name-choices.ts` で生成し、正答1件と異なる国3件を同地域の候補プールから選択します。Issue #7以降、UIは地図／国旗で `NameQuiz.tsx` を共有します。国IDと画面表示名の重複は排除し、乱数を注入できる純粋関数です。この候補生成処理はIssue #7の国旗→国名にも移植可能で、UI自体の完全共通化はIssue #18で行います。四択の回答結果は国IDで共通エンジンへ渡します。

回答後は結果を表示して「次へ」ボタンで進めます。パスは`skipQuestion()`を利用します。タイマーはReact側で250msごとに現在時刻を渡し、実際の時間切れ判定はエンジンの`tickSession()`に委譲します。言語切替は現在画面と回答の判定に適用されます。

## 検証と今後の対応

`npm run lint`・`npm run typecheck`・`npm test`・`npm run build`を確認します。テストは国マスタ197件、6地域、国名四択重複、特殊な小国の地図データを対象にしています。ブラウザでのPC・スマホE2E、視覚的なクイズUI検証、境界線の詳しい地理精度チェックは#13/#17で継続します。3D地球儀への対応はIssue #19です。
