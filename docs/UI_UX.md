# クイズ画面・スマホ/PC UI・アクセシビリティ（Issue #13）

## 画面フロー

メイン画面では **タイトル → 題型の選択（4つのカード）** の順に表示します。題型を選ぶと、そのクイズの **地域・回答方式/ルール設定 → 問題 → 正誤確認 → 結果** を1つのエリアで進めます。

- 起動直後には4つのゲームを全件表示せず、モード選択を最初に表示
- 選択したクイズの画面だけをマウント。スマホで複数の大きい地図や選択肢が縦に並ぶ問題を解消
- 「クイズ選択に戻る」でモード選択画面へ移動。**途中で戻るとその回の進行状況は破棄される**（保存/再開は未実装）
- ブラウザのハッシュ `#map-to-name-quiz` 等を読み込むと対応する題型を開く。リンククリック後・戻る操作後は適切な見出し/領域へキーボードフォーカスを移動
- 独立した地図・国旗のプレビューは折りたたみ式にし、開くまでレンダリングを遅延
- 「設定 / Settings」の言語切替は4題型の表示文言とゲーム中の国名に引き続き連動

## 共通部品

`src/features/quiz/QuizStatus.tsx` に、どの題型でも同じUIを使う部品を配置します。

| 部品 | 内容 |
| --- | --- |
| QuizProgress | 問題番号、出題上限、得点、残り時間。10問制では回答確定済み数に応じた進捗バーも表示 |
| QuizFeedback | ✓ / × / − の形状表示と、正誤・正解名・選択した誤答。次問ボタンにフォーカスを移動 |
| QuizResultSummary | 正答数・誤答数・スキップ・正答率・得点・経過時間。表示開始時に結果見出しへフォーカス |
| CountryChoiceGrid | 国名四択と国旗四択のクリック/タップと正誤スタイル。枠線の色だけでなく✓/×、誤答は破線でも区別 |

これらはゲームエンジンから得た `GameSession`・`GameResult` の表示だけを扱い、出題・採点の状態遷移は従来の共通ゲームエンジンで判定します。日英文言は従来どおり `quizMessages.ts` に保持します。

## 地図型の操作

`WorldMap` はマウスドラッグ・ピンチ・ホイール・地図上のタップ選択を維持します。回答方式の「国名 → 地図」では、国の選択後に独立した **回答を確定** ボタンを押す方式を維持し、ズーム・ドラッグを回答と誤認させません。

- マップ本体にフォーカスして矢印キーで表示位置を移動、＋／－でズーム
- 地図操作のボタン、表示エリアのセレクトは44px以上のタッチ領域
- 国ポリゴンのEnter/Space操作は現行の国選択機能を維持。形がごく小さい国も既存の透明ヒット領域でタップ可能
- 地図の説明文は `aria-describedby` で本体と関連づける
- 回答後には正解名と正誤のテキストも表示し、色の違いだけに依存しない

## レスポンシブとアクセシビリティ

- 画面幅が狭い場合、設定は縦方向へ畳み、国名選択肢は1列、**国旗四択は2列×2行**で表示
- 英語の長い国名も折返し、地図操作・回答確定ボタン・移動ボタンが重なりにくい配置
- 44pxを基本とした入力・操作領域。フォーカス状態はアウトラインで明示
- 国名を答える問題の旗画像のaltには正答国名を含めない（#7〜#12の対応を維持）
- 結果の見出し、回答後の次問ボタンへフォーカスを移し、画面下の結果を見落としにくくする
- `prefers-reduced-motion` では進捗バーのアニメーションを停止
- 将来広告を配置する場合、回答ボタン・地図のタッチ範囲と重ならない位置に独立の領域を設ける。本Issueでは広告配信自体は実装しない
