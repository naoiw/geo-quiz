# 国・旗・地図データ

## 決定済み

- 国連加盟193か国と国連オブザーバー2か国に台湾、コソボ等を追加する（Issue #2）。その他の対象・属領は最終リストで定義する。
- 国マスタの内部IDを国名、国旗、地図ポリゴンの結合キーとする。
- 表示言語は初期段階から日本語/英語を想定し、地域別モードにも対応する。

出題国の定義はゲーム上の選定であり、政治的地位の判断を示すものではありません。

## データソース候補（未採用）

- 国境: Natural Earthの地理データ等。小国・島・台湾/コソボ等の区分に注意する。
- 国旗: SVG等の旗画像。各素材の商用利用・再配布条件を確認する。
- 翻訳: Unicode CLDR等。表示名と回答で受理する別名は分ける。

Issue #1には実データ/第三者アセットを含めません。外部データのライセンスは、ソースコードのApache License 2.0とは別に確認します（Issue #2、#4、#17）。
