# 国名テキスト入力・読み仮名・表記ゆれ（Issue #10）

## 対象

地図→国名、国旗→国名の2つの「国名を入力」方式で、同じ国マスタと同じ判定関数を使います。四択は国マスタを表示名として使いますが、国IDを比較して判定するため、テキストの読み・表記ゆれを適用しません。

## 受理候補の管理

| 国マスタ項目 | 用途 |
| --- | --- |
| names.ja / names.en | 出題対象国の日本語・英語表示名 |
| aliases.ja / aliases.en | 明示的に許可した通称、正式名、別表記 |
| readings.ja（任意） | 漢字を含む日本語表示名や別名の読み |

表示名・通称・読みは、同じ言語のものだけで比較します。全197件に表示名があり、日本語表示名に漢字を含む23件には必ず読みを明示しました。国名の読みデータは計29件で、他の片仮名の国名はひらがなでも自動的に受理します。

**例：** 日本は「日本」「日本国」「にほん」「にっぽん」、アメリカ合衆国は「アメリカ」「米国」「べいこく」「あめりかがっしゅうこく」、中国は「中国」「中華人民共和国」「ちゅうごく」を受理します。コンゴ共和国とコンゴ民主共和国は明確に別名で、単に「コンゴ」と入力してもどちらも正解にはなりません。

通称や読みの登録は意図的に限定します。他言語でだけ登録された名前や曖昧な推測は受け付けません。

## 文字の正規化

入力値と国マスタの受理候補の双方に、次の処理を順番に行います。

1. Unicode NFKCで半角カナ・全角英数字・全角括弧などを標準化
2. アポストロフィの字体と、一部のハイフン・ダッシュの字形を統一
3. 前後空白の除去、連続空白の1文字化、括弧と中点の前後空白の除去
4. ひらがなをカタカナへ揃える（漢字からひらがなは自動生成しない）
5. 英字を大小無視で比較する。トルコ語由来の大文字 İ は結合点を除去して照合

最後は**完全一致**のみで判定します。部分一致、編集距離による誤字訂正、国名の勝手な省略、翻訳・ローマ字変換はしません。英語のアクセントも原則維持します。正解として認める追加表記はマスタに明示します。

実装は src/game-engine/engine.ts の normalizeTextAnswer()、getAcceptedTextAnswers()、judgeAnswer()。UIから独立した純粋関数であり、地図→国名と国旗→国名の両方から共用されます。

## IMEとスマートフォン

- IME変換中のEnterは送信しません。compositionstart/compositionend、nativeEvent.isComposing、keyCode 229および変換直後のEnterを扱います
- 日本語入力の確定と回答ボタンは別操作です。回答確定後は入力欄を無効にして正解を表示します
- 入力欄には enterKeyHint=done、自動大文字化OFF、自動補完OFF、スペルチェックOFFを設定します
- 説明文と入力欄を aria-describedby で関連付けます。空白だけの回答は送信できません

実機・ブラウザによるIMEイベントの細かな差のE2E検証は、後続の品質テストIssueで確認します。

## テスト

tests/text-answer.test.mjs にて197件の表示名・通称・読みの正答、日本語の読み、全角半角、ひらがな／カタカナ、厳密な不正解例、登録した別名が他国と衝突しないこと、表示言語別の独立した判定、両国名回答方式のUI接続を検証します。登録データを追加する場合も同じテストで衝突が検出されます。

画面言語の切替、初期値と保存、国名表示との連動については [LOCALIZATION.md](LOCALIZATION.md) を参照してください。
