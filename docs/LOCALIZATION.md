# 言語設定とローカライズ（Issue #12）

## 対応範囲

初期リリースから日本語（ja）と英語（en）の2言語に対応します。アプリのヘッダーにある「設定 / Settings」を開き、言語を選択すると**再読み込みなし**で表示が切り替わります。

- トップ画面、共通地図、地域選択、国旗プレビュー、4題型（回答形式を含めた6バリエーション）のUIを同時に切替
- 言語別に国名・国名選択肢、正解表示、回答履歴、地域名を表示
- 地図→国名・国旗→国名のテキスト入力は**現在の表示言語の受理名称だけ**を正解とする（Issue #10 の決定）。例えば Japan は英語モードで、日本・にほんは日本語モードで受理する
- 国ID・出題内容・得点は言語に依存しない。ゲームの途中で言語を変更しても進行状態を初期化しない
- HTMLの lang 属性、文書タイトルとdescriptionも選択言語に同期

## 初期言語と保存

1. localStorage の `geo-quiz:locale` に利用可能な言語コードが保存されていれば優先
2. 未保存・無効値の場合、ブラウザの `navigator.languages` を**優先順位の高い順**に調べ、最初に見つかった対応言語を選択
3. ブラウザの対応言語がなければ英語（en）にフォールバック
4. 選択した言語をlocalStorageに保存し、再訪時に復元する。ストレージを利用できないブラウザでも、そのセッション内の切替は利用可能

言語コードは ja / ja-JP / en / en-US などの言語サブタグを認識します。設定画面は HTML の `details` とラジオボタンでキーボード操作・スクリーンリーダーに対応します。

## 翻訳データの責務

| ファイル | 内容 |
| --- | --- |
| `src/i18n/messages.ts` | トップ画面・言語設定・HTMLメタ情報 |
| `src/i18n/quizMessages.ts` | 4題型・地域選択・世界地図で共用する日英文言 |
| `src/i18n/locale.ts` | 保存済み設定とブラウザの優先言語から初期言語を決定する純粋関数 |
| `src/i18n/useLocale.ts` | 言語設定を保持・保存し、文書言語とメタ情報を同期するReact hook |
| `src/country-data/countries.json` | 197件の言語別表示名、別名、読み |
| `src/country-data/regions.ts` | 地域の言語別表示名 |
| `src/game-engine/engine.ts` | 表示言語と正答国データを受け、現在の言語の名前・別名だけを厳密判定 |

翻訳キーは型で検査します。画面側では `translate()` / `quizText()` を使い、文字列長が変わっても設定パネルのレイアウトが崩れないよう幅を制限します。

## 新しい言語の追加

1. `Locale` に新しい言語コードを追加する
2. `messages.ts` / `quizMessages.ts` / `countries.json` / `regions.ts` に同じ言語のデータを追加する
3. 初期言語解決関数の許可言語と設定画面の選択肢を拡張する
4. 回答文言や動的な文の並び・フォント・レイアウトをレビューし、テストを拡充する

国名・回答の判定そのものは言語を引数に取る設計であり、**ゲームエンジンの出題・採点ロジックを変える必要はありません**。回答名の受理方針は [TEXT_ANSWER.md](TEXT_ANSWER.md) を参照してください。

## 検証

`tests/i18n.test.mjs` で言語の優先順位・無効値・フォールバック、日英の翻訳キー整合、197件の国名データ、ヘッダー設定画面と4題型の受け渡し、正答言語の独立を検証します。既存の全ゲームエンジン・地図・国旗・テキスト回答テストと併せてCIを実施します。
