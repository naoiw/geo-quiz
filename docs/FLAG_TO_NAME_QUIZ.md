# 国旗 → 国名クイズ（Issue #7）

## 画面と遊び方

トップ画面から「国旗 → 国名クイズ」を選択し、国旗を見て国名を入力または四択で回答します。表示言語は日本語・英語で切り替わります。

- 出題地域：全世界197件または6地域
- 進行：10問・時間無制限／10問・時間制限／タイムアタック
- 回答：テキスト入力または国名四択、パス、正誤・正解国名表示、次問へ
- 結果：スコア、正答率、回答数、経過時間、問題履歴
- 暫定の配点は正答100点、誤答・パス0点。時間制限も試験的な1・2・3・5分

## アセット・画面の共通化

- `src/flags/CountryFlag.tsx` は従来どおり国マスタの `flagId` から同梱SVGを取得します。ビルド時に全197件が存在することをテストします。
- クイズ時の画像代替テキストは国名を出さず「問題の国旗」／「Question flag」です（DOMの画像ファイル名には国IDを含みます）。
- `NameQuiz.tsx` に地図／国旗問題の回答入力、四択、パス、タイマー、採点、結果を集約。題型別の `MapToNameQuiz.tsx` と `FlagToNameQuiz.tsx` は同一コンポーネントのラッパーです。
- 四択は `name-choices.ts` で地域内の正答1件＋異なる国3件を生成し、テキストも含む正誤判定は `game-engine/engine.ts` で共通管理。
- 画像は配布元の4:3 SVGを縦横比維持で表示し、切り抜き・引き伸ばしをしません。正式な国旗の縦横比と異なることがあります。

## 似ている国旗の方針

採用素材 flag-icons v7.6.0の出題対象197件に**完全に同一のSVGファイルはありません**。ただしモナコ／インドネシア、チャド／ルーマニア、ルクセンブルク／オランダなど似た旗は存在します。

区別が難しい場合に配慮して、クイズには正解国の**地域（大陸）ヒント**を添えます。正誤は国IDで厳密に判定し、別の国を同じ正答とは扱いません。見た目の似た旗を問題候補から一律除外する仕組みは導入していません。画像の色差だけでは識別が難しい組合せは、今後の品質Issue #17で個別に評価します。

## テスト

`tests/flag-assets.test.mjs` は197枚のSVGと国ID・ライセンスの対応を検証します。`tests/flag-to-name-quiz.test.mjs` は出題・入力式・四択式・日英・共通UIの連携を検証します。より広範なブラウザE2Eと文字入力の表記ゆれは#17/#10の後続対応です。
