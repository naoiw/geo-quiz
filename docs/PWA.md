# PWA・オフライン動作（Issue #14）

## 対応内容

- GitHub Pagesのサブパス `/geo-quiz/` を維持して Web App Manifest とService Workerを配信します。
- Manifestには192px/512pxのPNGアイコンとSVGアイコンを同梱しています。ホーム画面への追加・スタンドアロン表示を想定しています。
- 本番/プレビューのビルドだけで Service Worker を登録します（Vite開発サーバーでは登録しません）。
- `npm run build` の後処理が `dist/` のビルド済み配信資産を検出し、全ファイルの内容ハッシュに基づくキャッシュ名を持つ `sw.js` を生成します。
- 初回オンライン読み込み・Service Workerのインストール完了後は、地図・197国旗・画面JS/CSS/HTMLをオフラインで利用できるようにします。外部CDNは不要です。

## キャッシュ・更新方針

- **初回:** Service Workerのinstallイベントでアプリ配信ファイル全件をprecacheします。途中で失敗した場合はオフライン利用を保証しません。
- **通常:** 同一スコープ内の静的ファイルはキャッシュ優先。ページ遷移はネットワーク優先とし、オフライン時にキャッシュした `index.html` を返します。
- **更新:** デプロイ時に1ファイルでも変わればキャッシュ名が変化します。新しいワーカーをインストールしてから旧`geo-quiz-*`キャッシュを削除します。既に開いているタブは新バージョンを受信してもリロードまで旧画面が残る場合があります。
- **範囲:** `import.meta.env.BASE_URL` を登録スコープに使用し、他のGitHub Pagesプロジェクトには干渉しません。
- **ブラウザ操作:** Service Workerおよびブラウザストレージを消去すると、次回は再度オンラインで読み込む必要があります。

PWAキャッシュに使用するアセットの更新履歴は `package-lock.json` とビルド成果物のハッシュから管理します。キャッシュに個人データや回答履歴は記録しません。

## 検証

CIで `tests/pwa.test.mjs` がManifest、アイコン、登録パス、キャッシュ一覧生成、ビルド内容変更に応じたバージョン更新を確認します。

**未実施の実機・ブラウザ確認：**

- [ ] 本番URLをAndroid Chromeで開き、ホーム画面への追加・起動を確認
- [ ] 初回オンライン訪問後、機内モードでリロードし、4題型・6形式の出題と国旗・地図描画を確認
- [ ] iOS Safariのホーム画面に追加し、オフラインで開くか確認
- [ ] 本番を更新後、再訪問で新しい内容へ更新し古いキャッシュが破棄されることを確認
- [ ] GitHub Pagesの `/geo-quiz/` 以外のプロジェクトへの副作用がないことを確認

詳細な実機検証結果は [QA_CHECKLIST.md](QA_CHECKLIST.md) とIssue #14に記録します。CIのみで端末固有のインストール動作は保証できません。
